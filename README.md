# Random Hexcode Generator #

tl;dr press button get random hexcode onto your clipboard :0

* * *


This project is an extension for the drawing tool Krita. It adds another menu option where you can get random hexcodes by clicking a button. This works using PyQt6 for the button and widget functionality, random for getting the hexcode, and pyperclip for pasting the hexcode you recieve to your clipboard.
